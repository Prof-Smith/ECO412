# Case Study 5: Redesign the Account

Select a budgeting, investment, subscription, pricing, travel, ownership, or payment environment. Produce a three-page design audit:

1. Identify the mental account and reference point.
2. Explain how gains and losses are integrated or segregated.
3. Separate product value from transaction utility.
4. Evaluate sunk cost, ownership, or payment timing.
5. Identify one adaptive benefit of the account.
6. Identify one distortion or welfare cost.
7. Recommend a transparent redesign and state a revision trigger.

Include one original Plotly chart or account-flow diagram.
