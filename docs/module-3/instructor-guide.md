# Module 3 Instructor Guide

## Teaching purpose

This module makes utility temporal. Students distinguish the utility used in choosing from the utility reported during an experience and the utility reconstructed afterward.

## Suggested debrief

1. Ask whether revealed preference alone can establish welfare.
2. Compare the weighted choice model with students' stated final choice.
3. Separate the temporal average from the peak-end estimate.
4. Discuss why a longer episode can be remembered more favorably when it ends better.
5. Use the anchor exercise to discuss preference construction without claiming one response proves susceptibility.
6. Distinguish acquisition utility from the perceived value of a deal.
