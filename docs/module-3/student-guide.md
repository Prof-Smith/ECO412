# Module 3 Student Guide

## Before starting

- Use the first response that feels natural.
- Treat every scenario as hypothetical.
- Do not enter personal financial, health, or identifying information.
- Complete the studios in order because later charts use earlier answers.

## Submission checklist

- [ ] Seven studios complete
- [ ] Utility JSON exported
- [ ] Utility Audit Memo complete
- [ ] At least four utility concepts applied correctly
- [ ] Decision-experience gap interpreted
- [ ] Anchoring result discussed cautiously
- [ ] Consumer-welfare implication included

## Interpretation rule

A choice reveals decision utility under the conditions of that choice. It does not automatically establish the experience that followed or the person's later retrospective evaluation.
