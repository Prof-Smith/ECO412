# Module 2 Field Study: Reliability in the Field

<div class="field-brief"><strong>Research question</strong><span>Would two observers classify the same choice environment in the same way?</span></div>

## Protocol

Select five publicly accessible decision environments. Two observers independently classify the most prominent feature at each location using the same codebook. Compare classifications only after both observers finish.

## Interpretation

Percent agreement is a simple descriptive reliability measure. It does not establish validity, causality, or generalizability. Discuss disagreements as evidence that the coding rule may need clarification.

## Field Note

Write 300–400 words:

1. What was the agreement rate?
2. Which category produced the most disagreement?
3. How would you revise the codebook?
4. What additional evidence would be required before claiming that the feature changes behavior?
