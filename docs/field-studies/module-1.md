# Module 1 Field Study: Choice Architecture Walk

<div class="field-brief"><strong>Research question</strong><span>How does a real decision environment make one option easier, more visible, or more likely than another?</span></div>

## Protocol

Visit three publicly accessible decision environments, such as a dining area, library service point, campus store, recycling station, event sign-up area, or online university service page. Observe the environment, not individual people.

For each location, record one feature from the list below. Do not photograph, record, follow, count, or identify people.

## Field Note

Write 300–400 words:

1. Which feature appeared most likely to influence choice?
2. What would the Standard Economic Model predict if the feature were irrelevant?
3. What alternative explanation could account for the observation?
4. What redesign would improve transparency or autonomy without restricting options?

!!! warning "Observation boundary"
    This activity studies environments. Do not collect information about people, infer personal characteristics, or make claims about behavior you did not measure.
