# Student Guide

## Before beginning

- Complete the lab individually before discussing answers.
- Use your actual first response rather than searching for a “correct” answer.
- Keep the same browser open until you export your profile.
- Do not enter names, student IDs, or other personal information.

## Submission checklist

- [ ] Complete all seven stations.
- [ ] Export the JSON profile.
- [ ] Print or save the dashboard as PDF if requested.
- [ ] Write the 500–700 word reflection.
- [ ] Connect at least three observations to course concepts.
- [ ] Include a responsible-stewardship discussion.

## Troubleshooting

If a chart does not appear, confirm that JavaScript is enabled and that the browser can load Plotly from the CDN. Refreshing the page preserves completed responses. Clearing browser site data removes them.

## Academic integrity

There is no prize for being “more rational.” The educational value comes from accurate responses and careful interpretation. The profile is not a measure of intelligence, character, or decision-making ability.
