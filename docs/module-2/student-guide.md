# Module 2 Student Guide

## Workflow

1. Complete the lab before viewing classmates' responses.
2. Treat every score as a design prompt, not a personal rating.
3. Export the preregistration JSON after completing Studio 6.
4. Submit the JSON and research audit memo through the LMS.

## Evidence language

Prefer bounded statements such as “in this sample,” “the observed difference,” and “the design supports.” Avoid claiming that one small study proves a universal behavioral law.

## Submission checklist

- [ ] Six studios complete
- [ ] Preregistration JSON exported
- [ ] Research question and hypothesis are testable
- [ ] Independent and dependent variables are distinct
- [ ] Assignment procedure is explicit
- [ ] Ethics safeguard is concrete
- [ ] Research audit memo is complete
