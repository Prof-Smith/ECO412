# Module 3 Lens: Experience Becomes Story

<div class="asl-hero asl-m3"><small>THE ADAPTIVE SPECIES • MODULE 3</small><h1>We live the stream and remember the ending.</h1><p>Prediction, choice, experience, and memory are different stages of adaptation, not interchangeable measures of welfare.</p></div>

## Principle

Decision utility supports choice. Instant utility describes moments. Total or average utility summarizes an episode. Remembered utility reconstructs the experience afterward.

## Dissent

The measures can diverge. Peaks, endings, anchors, expectations, and reference prices can influence what is chosen and what is remembered.

## Reversal

A compressed memory may be imperfect as a welfare measure yet useful for future action. An organism cannot preserve every moment equally. Memory may prioritize salient danger, reward, novelty, and the ending because those features help guide later approach or avoidance.

## The narrative problem

People live forward through uncertainty and understand backward through narrative. Once an episode ends, the remembered story can make the path feel cleaner and more inevitable than the experience itself.

## Five adaptive questions

1. What did the person predict before the episode?
2. Which moments dominated attention?
3. What did the ending change?
4. Which memory is guiding the next decision?
5. When would the compressed memory mislead future choice?

## Applied reflection

Compare the temporal average, the peak-end estimate, and remembered utility from one activity. Identify which measure is best for welfare assessment and which may be most influential for future behavior.

<div class="asl-takeaway"><strong>Adaptive takeaway</strong><span>Memory is not a recording. It is a decision input constructed after experience.</span></div>
